🔒 Privacy & Data Protection

  • ไม่มีการบันทึกข้อมูลงานนักเรียนบนเซิร์ฟเวอร์ — ข้อความเรียงความ/ข้อสอบถูกส่งตรงไปยังโมเดล AI ที่คุณกำหนด แล้วแสดงผลทันที ไม่เก็บลงฐานข้อมูล
  • API key ไม่อยู่ในหน้าเว็บ — กุญแจถูกเก็บไว้ฝั่ง proxy (serve.py) บนเครื่องของคุณเท่านั้น เบราว์เซอร์ไม่ได้รับและไม่สามารถเห็น key ได้
  • Audit log เก็บในเครื่องคุณ — บันทึกการแก้คะแนนอยู่ใน localStorage ของเบราว์เซอร์นี้ ไม่ถูกส่งออกไปภายนอก
  • โหมดสาธิต (Demo Mode) — ถ้าไม่ตั้งค่า key ระบบจะทำงานด้วยผลลัพธ์จำลองที่ติดป้าย "DEMO" ชัดเจน และไม่มีการเรียก API ใด ๆ
  • ข้อควรระวังจริง (เราไม่ปกปิด) — ข้อความที่ถูกส่งไปยังผู้ให้บริการ AI ภายนอกอยู่ภายใต้นโยบายข้อมูลของผู้ให้บริการนั้น หากงานนักเรียนมีข้อมูลส่วนบุคคล ควรลบออกก่อนส่ง หรือใช้โมเดลที่โฮสต์เอง (on-premise)
